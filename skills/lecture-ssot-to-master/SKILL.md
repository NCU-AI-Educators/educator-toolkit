# Lecture SSOT-to-Master Pipeline (从 `ssot.md` 到 `master.md` 五层精炼与衍生总管)

> [!IMPORTANT]
> **定位说明**：本技能衔接 `/lecture-pipeline` 前置教案与 `*.ssot.md`（单一事实源教材母稿）成型之后的**后置全链路精炼与多端编译工程**。
> 当目录中已存在 `<讲次>.ssot.md` 时，直接唤醒本技能，按以下 **7 个阶段（Stage A ~ Stage G）** 严格顺序执行。

## Stage A：清洗 `ssot.md` 的 AI 味与排版规范

在将 `*.ssot.md` 转化为幻灯片之前，**必须先对源头母稿 `*.ssot.md` 执行彻底的文风清洗**，防止上游 AI 腔调向下游幻灯片、逐字稿与自学导读扩散。

1. **执行 V11 学术与工程语态清洗（调用 [`../lecture-n06-content-purifier/SKILL.md`]）**：
   - **清除自媒体与武侠浮夸词**：全量扫描并替换“级联雪崩、降维打击、认知破局、深水区、练兵场、试金石、赋权、跃迁、心智主权、代码体力流、坚不可摧、毫秒级/秒级响应”等黑名单词汇；
   - **消除伪学术生造词与机械直译**：将非数学语境下的“正交”替换为“相互独立 / 职责无交叉”；将非硬件语境下的“物理隔离 / 物理意义”替换为“底层隔离 / 实际层面”；将泛化滥用的“高保真”替换为“无损矢量 / 排版合规”；
   - **短句拆解与去名词堆砌**：拆分超过 50 字无标点的长定语链，还原清晰的“主语 + 动词 + 宾语”工程表述；
   - **事实与数据锚定**：所有核心论断必须锚定真实计算机科学文献（如 NATO 1968、Parnas 1972、Brooks 1975、Boehm 1981、METR 2025、DORA 2024）或可复现的工程案例。
2. **中英文与加粗间距规范化（调用 [`../markdown-cjk-spacer/SKILL.md`]）**：
   - 对 `*.ssot.md` 执行 CJK 行内格式串空格填充，确保紧贴中文的 `**加粗**`、`**“加粗引号”**`、`` `行内代码` `` 前后保留半角空格（代码块内部除外）。
3. **重编译 SSOT 教材 PDF（可选，调用 [`../typst/SKILL.md`]）**：
   - 若目录中维护了 `<讲次>.ssot.a4.typ` 与 `<讲次>.ssot.a4.pdf`，同步更新以确保长文教材与后续幻灯片同源一致。

## Stage B：基于清洗后的 `ssot.md` 构建 `master.md`

以清洗完毕的 `<讲次>.ssot.md` 为唯一输入源，构建包含完整可视区排版与底部注释隔离舱的 `<讲次>.master.md`（若结合 `md2slide` 渲染引擎，则同步维护 `<讲次>.final.md` 并映射为 `<讲次>.master.md`）：

1. **课时与页数规划**：
   - 标准高校课堂讲义按 **21 页左右（1 页封面 + 20 页正文，每页对应约 2 分钟讲授节奏）** 切分知识切片；
   - 每页遵循“一页一核心教学切面”，将概念演进、架构图解、正反对比、工业实证、随堂测验与课后实训合理分布。
2. **单页五层标准结构协议（兼容 `scripts/generate_materials.py`）**：
   每一页幻灯片由 **1 个可视区正文层** 与 **最多 4 个 HTML 注释元数据舱** 组成：

3. **高信息密度学术 SVG 插图设计规范（严格对齐第 1、2、3 讲视觉基准，拒绝简陋线框图）**：
   - **封面背景图（`figures/<讲次>_slide_01_cover_bg.svg`，`1280×720`）**：
     - **严禁使用深色背景或不透明白底卡片**：由于 `.tpl-md2slide-cover` 采用横跨全屏的深色大标题与底部章节卡片，封面 SVG 必须采用**浅色半透明工程蓝图（Subtle Engineering Blueprint）**（`#f8fafc -> #f1f6fb -> #e5eff8` 基底渐变 + `56×56` 带十字刻度的 `blueprint-grid` 细网格 + `glow-celadon` / `glow-slate` 柔光光晕）；**严禁在封面背景图中绘制不透明白底矩形卡片、实心中文胶囊标签或与封面排版争抢视觉焦点的正交信息框**；

     - **标准三段式外框**：外层统一采用 `#FFFFFF` 圆角白底卡片（`rx="10" stroke="#CBD5E1" stroke-width="1.5"`）+ **顶部标题栏**（`#F8FAFC` 底色、左侧主题色圆点、14px 加粗主标题、右侧圆角胶囊等宽徽标如 `WIENER 1948` / `REACT × SWE-BENCH`）+ **底部核心结论栏**（`#F1F5F9` 底色 + `◀ 一句话定量/定性核心结论 ▶`）；

## Stage C：五层内容依次精炼与去 AI 味净化 (5-Pass Purification)

构建 `<讲次>.master.md` 后，**严禁一锅端式粗略扫视或用正则批量替完交差**，必须**从第 1 页到最后一页逐页通读**，并严格按照以下 **5 个独立轮次（Pass 1 ~ Pass 5）** 依次对每一层执行专项精炼与净化：

### Pass 1：净化【正文 (Slide Body)】（对齐 [`../lecture-n05-slides-writer/SKILL.md`] & [`../lecture-n09-layout/SKILL.md`]）
1. **双流编码理论（Dual Coding Theory）容量预算与满高插图铁律**：
   - **视觉通道减负硬指标**：依据 Paivio 双流编码理论，幻灯片可视区（`.fr-body`）仅承担“视觉锚点”功能，完整因果推导与故事细节必须下沉至听觉通道（`逐字稿`）与课后阅读通道（`解释`）。全篇 `.fr-body` 平均字数必须严格控制在 **$155\sim 165$ 字/页**（对齐第 1 讲 `164` 字/页基准），单页 `.fr-body` 最高不得超过 **$190$ 字**；
   - **电报式要点与大字号标准**：主标题 `##` $\le 18$ 字，禁止使用悬念式或公众号标题党；单页卡片 $\le 4$ 组，每条要点控制在 **$18\sim 28$ 字以内**（采用 `**4～6字锚点词**：电报式核心短语` 结构，删去冗余主语和连词）；全局页面字号统一提升至 **`fs-24`～`fs-28`**（`r46` 宽幅图页不低于 `fs-23`），**严禁为了塞下长句而将字号缩小至 `fs-20`～`fs-21`**；
   - **信息图页强制 `r55` / `r46` 满高渲染与左栏防截断字号铁律（严禁使用 `r64`）**：`573×478` 标准信息图（`.svg-arch-infographic`）必须搭配 **`r55`**（使 `.fr-figure` 宽度保持 `573px`），`688×474` 宽幅信息图必须搭配 **`r46`**（使 `.fr-figure` 宽度保持 `688px`），从而保证右侧 SVG 在 `object-fit: contain` 下实现 **100% 垂直满高填充（`drawnSVG height = 463px～521px`）**。同时，由于左侧容器 `.svg-info-left` 固定高度为 `463px` 且超出部分会被父容器截断（此时单个 `.fr-card` 自身 `scrollHeight == clientHeight`，但 `.svg-info-left` 的 `scrollHeight > clientHeight` 且末尾卡片 `bottom > left.bottom`），左栏字号与单卡字数必须严格遵守以下几何红线：
     - **左栏 3 张卡片（`r55`）**：使用 **`fs-22 r55`**（若全为 $\le 34$ 字短句可用 `fs-24 r55`），每张卡片仅限 1 条要点、严格控制在 **2 行以内（可见字符 $\le 38$ 字）**，严禁折成 3 行；
     - **左栏 3 张卡片（`r46` 宽幅图，左栏仅占 40% 宽）**：使用 **`fs-21 r46`**，每张卡片仅限 1 条要点、严格控制在 **2 行以内（可见字符 $\le 35$ 字）**；
     - **左栏 4 张卡片（`r55`）**：必须使用 **`fs-20 r55`**（严禁在 4 卡双行时使用 `fs-24 r55`，否则 4 张卡总高 `506px > 463px` 必导致第 4 张卡下半部被截断！），每张卡片仅限 1 条要点、严格控制在 **2 行以内（可见字符 $\le 32$ 字）**；
   - 卡片标题 `###` 必须精炼（纯组件横向卡片左栏 `h3` 控制在 $6\sim 8$ 字以内，普通卡片控制在 $10\sim 14$ 字以内），确保在 16:9 宽屏与 A4 竖版下均**单行完整显示、不折行**；
   - **严禁在窄栏卡片内使用整句不换行的 `$\text{中文长等式}$` 公式块**：KaTeX 渲染单个 `$ ... $` 容器时默认强制不换行（`white-space: nowrap`），在双栏/三栏卡片（`.fr-card`）内包裹长中文等式（如 `$\text{可靠代码智能体 (Agent)} = \text{概率大模型 (Model)} + \text{确定性驾驭层 (Harness)}$`）会导致右侧水平截断溢出（`scrollWidth > clientWidth`）。必须将中文名词与行内代码置于 `$ ... $` 外部（如 `可靠代码智能体（`Agent`）$=$ 概率大模型（`Model`）$+$ 确定性驾驭层（`Harness`）`），确保在窄卡片内可自然折行。
2. **语态克制与母稿编号剥离**：
   - 彻底删除“极其、极具、彻底、绝对、满血、王牌”等无信息量修饰词；
   - **剥离母稿图表序号**：幻灯片正文、导语（`.fr-lead`）与注释舱中严禁残留 `ssot.md` 母稿的 `（图 3-1）`、`（表 3-2）` 等跨文档编号，统一改为直接指代本页元素（如“对照四维核心清单”、“如右侧闭环图所示”）；
   - **繁简字全面排查**：全量扫描并修正混入的繁体字（如 `風險` $\rightarrow$ `风险`、`刪掉` $\rightarrow$ `删掉`、`體系` $\rightarrow$ `体系`）；
   - 禁止在提示框或标题中使用说教式第二人称（“你必须记住”、“帮你搞定”），改为客观第三人称工程陈述。

### Pass 2：净化【逐字稿 (Script)】（对齐 [`../lecture-n07-script-writer/SKILL.md`]）
1. **出声朗读测试（Read-Aloud Test）**：
   - 每一页逐字稿开头标注建议讲授时长（如 `*(2 分钟)*`），首句自然承接上一页结论；
   - 句子必须是自然口语短句（单句不超过 45 字），先说结论再说原因，彻底拆解长定语链。
2. **严禁复读正文与造词，空间指代严密对齐 SVG**：
   - 逐字稿是讲台上的口头拆解、举例与引导看图，严禁把幻灯片正文逐字照念一遍；

每完成一讲或一个单元的 `master.md` 定稿后，同步从本讲核心知识点、实证案例与工程公式中提炼 **10 道高质量练习题**（8 道单选 + 2 道多选）：

   - **选项长度红线**：每个选项严格控制在 **单行 35～42 个汉字以内**，对仗工整、干脆利落，严禁把选项写成冗长段落。
2. **超星学习通一键导入版（`可导入学习通平台.md`）**：
