# Lecture Node 6: 内容净化与五层顺序清理器 (5-Layer Sequential Content Purifier)

作为讲义大流水线与方法论写作的 **Node 6 核心净化节点**，本技能用于对 `*.ssot.md` 教材母稿执行 V11 学术语态清洗，并对包含可视区与隐藏注释舱的 **`*.master.md`（或 `*.final.md`）按固定五步顺序依次清理【幻灯片正文 $\rightarrow$ 逐字稿 $\rightarrow$ 对白 $\rightarrow$ 自学解释 $\rightarrow$ 教学设计】**，彻底杜绝“只洗幻灯片表面正文、漏洗底部四大 HTML 注释块”的常见遗漏。

---

## 一、 核心净化原则与红线 (Core Principles & Safety Rules)

1. **五层逐一过筛，严禁跳步或只洗表面**：
   - 面对 `*.master.md` 时，必须严格按照 **Pass 1（幻灯片正文）$\rightarrow$ Pass 2（逐字稿）$\rightarrow$ Pass 3（对白）$\rightarrow$ Pass 4（自学解释）$\rightarrow$ Pass 5（教学设计）** 的顺序分轮次清理，每一轮只聚焦当前层的语态规范与结构红线。
2. **客观理性，拒绝抒情与自嗨**：
   - 彻底剔除文学化、情绪化、营销号式的夸张形容词与副词；
   - 以第一性原理、严密逻辑因果与客观实验数据作为唯一的论证载体。
3. **术语精准，拒绝机械直译与生造词**：
   - 严厉打击将英文生硬直译为怪异中文的翻译腔（如“级联”、“正交”、“高保真”泛化滥用），以及大模型强行拼凑的四字伪学术词（如“代码体力流”、“底座核域”、“执行剥离切割”）。
4. **单页原子修改与 UTF-8 闭环保护**：
   - 手工或脚本修改 `*.master.md` 时，必须以 `---` 为物理边界逐页处理，或通过内存完整校验 `content.encode('utf-8').decode('utf-8') == content` 后执行整文件原子写入，严禁跨页大段模糊替换。

## 三、 五层顺序清理标准工作流 (Sequential 5-Pass Workflow)

当对 `<讲次>.master.md` 执行清理时，首先运行五层分步诊断脚本掌握全书违例分布，然后**严格按 Pass 1 $\rightarrow$ Pass 5 依次清理**：

```bash
# 1. 全量五层只读诊断（查看 Pass 1 ~ Pass 5 每层每页的具体违例项）
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py "<讲次>.master.md"

# 2. 按层依次执行确定性自动修复 + 人工/LLM 精修复核
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py --pass 1 --fix "<讲次>.master.md"
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py --pass 2 --fix "<讲次>.master.md"
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py --pass 3 --fix "<讲次>.master.md"
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py --pass 4 --fix "<讲次>.master.md"
python3 ~/.gemini/config/skills/lecture-n06-content-purifier/scripts/purify_master_5layers.py --pass 5 --fix "<讲次>.master.md"
```

### Pass 1：清理【幻灯片正文 (`Slide Body`)】（`--pass 1`）
- **审查范围**：每张幻灯片处于 HTML 注释块（`<!-- ... -->`）之外的全部可视区内容（含 `##` 标题、导语框、分栏卡片、代码注释与底部总结框）。
- **核心清理动作**：
  1. **清除 V11 黑名单词与标题党标点**：替换所有浮夸修辞与机械直译词；清除 `##` / `###` 标题中的感叹号 `！` 与悬念式标题党。
  2. **剥离母稿跨文档图表号**：彻底清除从 `ssot.md` 复制残留的 `（图 9-1）`、`（表 9-2）`、`参见 9.3.1 节` 等跨文档编号，统一改为本页空间自然指代（如“如右侧架构图所示”、“对照下方参数表”）。
  3. **消除说教式第二人称**：将提示框或卡片中的“你必须记住”、“帮你搞定”改为客观第三人称工程陈述（情境导入页的角色扮演除外）。
  4. **HTML 容器配对校验**：确保本页所有 `<div ...>` 与 `</div>` 数量严格相等、缩进闭合完好，绝不触碰或破坏 CSS 类名与图片路径。
  5. **标题讲台试读与跨页序号核验**：所有 `##` / `###` 标题按讲台自然口语念一遍，杜绝汇报腔大词（如“指令演进/代码解构/注入上下文”）；严禁对非并列/非递进页强贴 `（上/中/下）`、`（一/二/三）` 序号，且连续分篇序号前的主干前缀必须逐字一致。

### Pass 2：清理【逐字稿 (`类型: 逐字稿`)】（`--pass 2`）
- **审查范围**：所有 `<!-- - **类型**: 逐字稿 ... -->` 注释舱。
- **核心清理动作**：
  1. **出声朗读测试与长句拆解**：逐页检查逐字稿，将超过 45 个汉字无标点停顿的书面化长定语链（如“针对海量底层数据的标准探索与清洗方案”）拆分为“先说结论、再说原因”的自然口语短句。
  2. **人称红线清理（对齐 `lecture-n07-script-writer`）**：全面清除逐字稿中的 `你`、`你们`、`你的`、`帮你`、`咱们`，指代听众统一用“大家”或省略主语，指代操作主体统一用“研究者”或“开发者”。
  3. **严禁照念 PPT 与 AI 造词**：删除与幻灯片卡片完全雷同的复读句，将“执行剥离切割”、“拉起无菌真空舱”等 AI 生造词还原为平实讲课语言（如“把异常数据剔除”、“搭建独立虚拟环境”）。
  4. **图文空间指代对齐**：核对逐字稿中的看图引导词（如“请看屏幕右侧流程图”）是否与本页实际配图布局一致，清除任何 `图 X-Y` 或 `.svg` 文件名残留。
  5. **句末换行与 2 空格缩进（对齐 `lecture-n11`）**：确保逐字稿内每个完整句子（`。`）后独立换行，且注释块内部保持统一的 2 空格缩进。

### Pass 3：清理【对白 (`类型: 对白`)】（`--pass 3`）
- **审查范围**：所有 `<!-- - **类型**: 对白 ... -->` 双人播客/师生剧场注释舱。
- **核心清理动作**：
  1. **清零情绪化拟声与吹捧赞叹词（最高优先级）**：
     - 彻底删除 `【助教Alice】` / `Host B` 台词开头的 `哈哈`、`哇！`、`天哪`、`哎呀`、`噢！`、`对对对`、`太扎心了`、`太形象了`、`太透彻了`、`太真实了`、`太巧妙了`、`太清爽了`、`太震撼了`、`一针见血`、`醍醐灌顶`、`豁然开朗`、`比喻得特别到位` 等小品式捧哏套话。
  2. **清零教师居高临下的评判套话**：
     - 彻底删除 `【教师Hawk】` / `Host A` 回复开头的 `完全正确`、`非常准确`、`一点不错`、`问到点子上了`、`抓到了核心`、`观察得非常仔细`、`说得非常透彻`、`满分通关` 等机械表扬前缀，改为直接切入底层机理、反例推演或代码边界。
  3. **严控感叹号密度（$\le 1$ 个/页）**：
     - 将陈述句末尾滥用的感叹号 `！` 替换为句号 `。` 或问号 `？`，确保**单页对白中的 `！` 总数严格 $\le 1$**。
  4. **去视觉化与称谓规范（对齐 `lecture-n07b-podcast-dialogue`）**：
     - 清除“如左图所示”、“大家看这张图”等依赖屏幕画面的表述（音频听众无法看图，应直接讨论组件关系或代码行为）；
     - 老师直呼助教名字（`Alice`），助教称呼老师为 `Hawk老师` 或 `老师`，严禁在台词中生硬互称职位名“助教”、“教师”。

### Pass 4：清理【自学解释 (`类型: 解释`)】（`--pass 4`）
- **审查范围**：所有 `<!-- - **类型**: 解释 ... -->` 学生课后自学导读注释舱。
- **核心清理动作**：
  1. **清零教研员黑话倒灌（对齐 `lecture-n08-deep-dive`）**：
     - 彻底清除“旨在引导学生……”、“培养学生……”、“考查学生……”、“依据布鲁姆教育目标分类学”、“加涅九步”、“认知梯度”、“课程思政融入点”等面向督导的第三人称教案用语，改为直接面向自学学生的“书边离线私教”语态。
  2. **清零底层文件名与母稿编号泄露（铁律）**：
     - 严禁向学生暴露底层图片文件名（如 `fig20_01.svg`、`177463.png`）、CSS 类名（如 `.prompt-card`）或 `ssot.md` 跨文档编号（`图 9-1`、`表 9-2`），统一改写为“如本页架构图所示”、“结合上方代码卡片”。
  3. **规范三段式结构与标题前缀**：
     - 移除 `###` 标题中冗余的 `【自学导读】` 前缀（由 `generate_materials.py` 自动挂载 `<strong class="box-title">[自学导读]</strong>` 徽章）；
     - 确保每页包含充实的 **核心结论 / 核心机理深度拆解**、**实战踩坑与认知排雷**、**自学思考与行动建议**（控制在 $250\sim 350$ 字左右，拒绝三五行敷衍空话）。

### Pass 5：清理【教学设计 (`类型: 教学设计`)】（`--pass 5`）
- **审查范围**：所有 `<!-- - **类型**: 教学设计 ... -->` 教师备课注释舱。
