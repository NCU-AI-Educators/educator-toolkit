# Markdown CJK Spacer 技能 (中文字符与行内格式串空格补全技能)

> **基于词法 Token 识别的 Markdown 中文与行内格式串（加粗、斜体、行内代码、删除线）盘古之白自动补全引擎**

[![Python](https://img.shields.io/badge/Python-3.8+-3776AB.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-AGPL%20v3-blue.svg)](../../LICENSE)

---

## 📖 技能定位

在中文 Markdown 写作与 AI 生成内容整理过程中，行内格式标记（如 `**加粗**`、`**“加粗引号”**`、`` `code` ``、`*斜体*`）若直接紧贴前后中文字符，不仅在视觉上显得拥挤粘连，还会触发 CommonMark 解析器在中英文标点交界处的闭合失效（导致页面直接裸露 `**` 符号）。

同时，若使用朴素正则表达式（如 `(\*\*[^*]+\*\*)`）盲目替换，当同一行内存在两个及以上加粗块时，极易将前一个加粗块的结尾 `**` 与后一个加粗块的开头 `**` 发生 **跨块倒置误匹配**，在加粗符号内侧误插空格从而破坏 Markdown 语法。

**Markdown CJK Spacer（`/markdown-cjk-spacer`）** 采用词法 Token 状态机与边界防误伤机制，精准扫描指定文件或整个工程目录，为所有紧贴汉字的行内格式串外侧自动补齐对称半角空格。

---

## ✨ 核心特性

### 1. 全谱系行内格式串识别
| 匹配模式 | 修复前示例 | 自动补全后效果 |
| :--- | :--- | :--- |
| **加粗内嵌引号** | `采取**“急用先行”**的策略` | `采取 **“急用先行”** 的策略` |
| **标准加粗** | `呈现**多源异构**的特征` | `呈现 **多源异构** 的特征` |
| **行内代码** | `调用`readsb`进行解调` | `调用 `readsb` 进行解调` |
| **引号外嵌加粗** | `向“**自主研判**”的演进` | `向 “**自主研判**” 的演进` |

### 2. 四重安全与边界防误伤机制
1. **围栏代码块完全免疫**：被 ` ``` ` 或 `~~~` 包裹的多行代码块严格保持原状，绝不侵入修改；
2. **数学公式块完全免疫**：被 `$$` 包裹的单行或多行公式块严格原样保留；
3. **杜绝跨加粗倒置误伤**：采用词法 Token 判定机制，对于同一行内多个独立加粗块（如 `**概述**：本方案立足于**现实**`），严格识别内部标点与边界，绝不发生跨块误拼接或内侧插空格；
4. **双反引号转义保护与幂等性**：支持 ```` `` `code` `` ```` 双反引号语法，且多次重复运行完全幂等，绝不重复叠加空格。

## 💬 智能体交互指南：自然语言与斜杠命令

### 1. 斜杠命令直接调用 (Slash Commands)

```bash
# 1. 对单个 Markdown 文档执行就地空格补全
/markdown-cjk-spacer docs/调研报告.md

# 2. 扫描并修复当前工作区下所有 Markdown 文档
/markdown-cjk-spacer .
```

### 2. 终端命令行直接运行

```bash
# 预览检查模式（仅输出统计与命中行号，不修改文件）
python3 skills/markdown-cjk-spacer/scripts/spacer.py < file_or_dir >

# 就地修改保存模式 (-i / --inplace)
python3 skills/markdown-cjk-spacer/scripts/spacer.py < file_or_dir > -i
```
