# Hawk Styled Markdown Preview

Preview and export your Markdown files using a beautiful, academic-styled template. 

## Features

- **Rich Preview**: Styled with modern typography, supports math (LaTeX) via MathJax, and custom containers.
- **Export to HTML**: Save your styled markdown as a standalone HTML file with one click.
- **Math Support**: High-quality rendering for inline `$E=mc^2$` and block `$$...$$` math.
- **Auto-Scroll**: Press `Space` in preview mode to toggle auto-scrolling (Teleprompter mode).
- **Custom Syntax**: Supports Ruby/Pinyin syntax `[Text]{pinyin}` and GitHub-style alerts `[!NOTE]`.

## Usage

1. Open any Markdown (`.md`) file.
2. Click the **Eye icon** (`$(eye)`) in the editor title bar (top-right).
3. In the preview window, click the **Export HTML** button to save.
4. Press `Space` to toggle auto-scroll.

## Extension Settings

This extension contributes the following commands:

* `mdStyledHtml.preview`: Open the styled preview.
* `mdStyledHtml.export`: Export the current markdown to HTML.
