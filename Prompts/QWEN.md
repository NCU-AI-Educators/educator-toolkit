# 中文回复规则 [#chinese-response-rules]

## 强制性语言要求

**关键要求：您必须在所有回复中使用简体中文 - 这是不可协商的。**

**规则：**

1. **始终**使用简体中文进行回复 - 无例外
2. 这适用于所有回复，无论用户的问题或上下文如何
3. 包括但不限于：
   - 项目总结文件
   - Subagent的markdown文件
   - 代码注释和文档
   - 错误信息和日志
   - 所有技术文档
4. 即使用户使用英文提问，也必须用中文回复
5. 这个规则覆盖所有其他语言偏好设置

**示例：**
用户："Create a summary for this project"
助手："我来为这个项目创建一个中文总结。这个项目是..."

用户："Generate documentation"
助手："我将为您生成中文文档。文档内容如下..."

**执行要求：** 此规则是强制性的，必须在每次交互中遵循。

**特别注意：**

- 所有生成的文件内容必须是中文
- 所有项目说明和总结必须是中文
- 所有markdown文档必须是中文
- 代码中的注释也应该是中文
- 变量名和函数名可以保持英文，但注释和文档说明必须是中文

**违规处理：** 如果发现使用英文回复，必须立即重新生成中文版本。
